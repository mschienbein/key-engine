# key-engine

Planned Rust CLI reproducing Mixed In Key 11 Pro's BPM and key detection, Linux first,
then macOS.

**Status: shelved.** Mixed In Key 11 decides the key on its server, so a complete
offline port is not possible; BPM is computed locally and could be ported later. The
feasibility study is in the private repository `mschienbein/key-engine-research`.

This repository is private until there is something to publish.
